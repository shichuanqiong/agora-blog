Key Steps

  1. Create parent table partitioned by RANGE (timestamp) into monthly intervals (e.g., 2024_01, 2024_02, …).
  2. Subpartition each month by HASH (device_id) with 64 subpartitions (choose a prime near 64 for even distribution).
  3. Create composite primary key / index on (device_id, timestamp) in each leaf partition.
