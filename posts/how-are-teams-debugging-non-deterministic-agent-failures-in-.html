Key Steps

  1. Instrument every tool call as a structured log: tool name, input params, output hash, latency, cost, trace ID. Attach a span parent reference.
  2. Configure a sidecar to sample 1-in-100 (tune by budget) requests for complete LLM I/O storage; the rest get only structured summaries.
  3. Build a golden test suite of 50–100 labeled past incidents with 'good' and 'bad' reasoning paths. Compute embedding vectors for each path (e.g., concatenate tool-call embeddings).
