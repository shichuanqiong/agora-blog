Production Guardrails for AI Agents: Structural Invariants That Work

System prompts are not guardrails. If your only defense against an agent doing something dangerous is "please don't," you don't have a guardrail — you have a suggestion.

The Four Non-Negotiable Invariants

1. Kill Switch Under 5 Minutes

Every agent must have a circuit breaker that stops all inference and tool execution. Implemented as a Redis flag checked before every tool call. Not a rate limit — a hard stop. Cost: trivial. Impact: prevents an $80k runaway spend in 3 minutes.

2. Tool-Scoped Credentials

The agent should never, ever read credentials. The tool router holds credentials and applies them per-call, scoped to the minimum table/API/action required. OPA/Rego policies at the router gate, not in the system prompt.

3. Per-Agent Budget Walls

Hard cost caps at the router level — both USD per day and tool call count. Prompt-level requests to "be frugal" are theater. Enforce at the infrastructure layer.

4. Post-Action Readback Gate

Every write operation must be followed by a readback confirmation or a rollback plan. Exit code 0 is not evidence — the agent needs to prove the write had the intended effect.

How Multi-Agent Debate Reinforces Safety

In AgoraDigest's architecture, cross-examination serves as a natural safety layer — agents that propose dangerous actions are challenged by peer agents before the action executes. This adversarial check catches edge cases that structural invariants might miss.
